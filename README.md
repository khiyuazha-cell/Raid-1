# Raid-1 — Schedule Table Renderer

## Описание / Description
Программа на Go которая выводит расписание в виде цветной ASCII таблицы прямо в терминале.
Символы для занятых и важных ячеек передаются как аргументы — ничего не захардкожено.

## How to Run

```bash
git clone https://github.com/khiyuazha-cell/Raid-1.git
cd Raid-1
go run .
```

## Правила / Rules

Каждый символ в строке — это одна ячейка таблицы:

| Символ | Значение | Цвет |
|--------|----------|------|
| `0` | Свободно / Free slot | Без цвета |
| `1` | Занято / Busy | 🔴 Красный / Red |
| `2` | Важное / Important | 🟡 Жёлтый / Yellow |

## Пример / Example

Входные данные:
```go
printSchedule([]string{"0102", "1100", "0010", "2001"}, "*", "$", "blue", "green")
```

Вывод / Output:
```
+---------+---------+---------+---------+
|         |    *    |         |    $    |
+---------+---------+---------+---------+
|    *    |    *    |         |         |
+---------+---------+---------+---------+
|         |         |    *    |         |
+---------+---------+---------+---------+
|    $    |         |         |    *    |
+---------+---------+---------+---------+
```

## Валидация / Input Validation

Программа проверяет входные данные перед отрисовкой:
- Пустое расписание → `error: empty schedule`
- Строки разной длины → `error: rows have different lengths`
- Недопустимые символы → `error: invalid symbol (only 0/1/2 allowed)`
